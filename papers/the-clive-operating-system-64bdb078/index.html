The Clive Operating System

  • Authors:
  • Francisco J. Ballesteros
Read the paper
Published: October 4, 2014 (Lsub Technical Report 14-4)

📜 Abstract

Clive is an operating system aimed at providing simple and high performance construction of network and cloud services. Currently it is used hosted on other systems to support further development of the system. In the future it will also run on native blades. Clive introduces new file system technology and novel interfaces for the construction of networked system.
